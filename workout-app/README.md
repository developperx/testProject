# KINTORE — 筋トレ記録アプリ 💪

ブラウザだけで動く、インストール不要・ビルド不要の筋トレ記録アプリです。
データはすべて端末のブラウザ（localStorage）に保存されるため、オフラインでも動作し、外部にデータが送信されることはありません。

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# 簡易サーバーで起動する場合
cd workout-app
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

スマートフォンでの利用を想定したレスポンシブUI（ダークテーマ）です。

## 主な機能

### 🏋️ 記録
- 日付ごとに種目・セット（重量×回数）を記録
- 31種のデフォルト種目（BIG3を含む、部位別に整理）＋カスタム種目の作成
- **前回の記録を自動表示** — プログレッシブオーバーロードを意識したトレーニングをサポート
- セット追加時は前セットの値を自動入力
- セット完了時に **PR（自己ベスト）を自動検出** して通知

### ⏱ レストタイマー
- セット完了チェックで自動スタート（ON/OFF・時間は設定で変更可能）
- ±15秒調整・スキップ・バイブレーション通知（対応端末のみ）

### 📅 履歴
- カレンダー表示でトレーニング日をひと目で確認
- 日ごとの種目・セット・総ボリュームのサマリー
- 過去の記録の編集・削除

### 📈 統計
- 今月のワークアウト数・週単位の連続記録（ストリーク）・総ボリューム・総セット数
- 週間ボリュームの棒グラフ（直近8週間）
- 種目ごとの **推定1RM（Epley式）の推移グラフ**
- 部位別ボリューム分布（直近30日）
- 全種目の自己ベスト一覧

### ⚙️ データ管理
- JSON形式でのエクスポート／インポート（バックアップ・機種変更に対応）

## 技術構成

- Vanilla JavaScript / HTML / CSS のみ（依存ライブラリなし）
- グラフはSVGを直接生成（チャートライブラリ不使用）
- データ保存: `localStorage`（キー: `kintore_data_v1`）
